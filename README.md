## Description

Movie App is a mobile application built using React Native and Expo. It serves as a platform for users to explore and manage a collection of movies, providing a welcoming interface for movie enthusiasts.

## Installation

To get started with the Movie App, clone the repository and install the necessary dependencies using npm:

```bash
git clone https://github.com/JesseJohn7/Movie-app.git
cd Movie-app
npm install
```

## Usage

You can start the application in different environments using the following commands:

- To run the app on Android:
  ```bash
  npm run android
  ```

- To run the app on iOS:
  ```bash
  npm run ios
  ```

- To run the app in a web browser:
  ```bash
  npm run web
  ```

- To start the development server:
  ```bash
  npm start
  ```

## Features

- **Responsive Layout**: The app uses Expo Router for smooth navigation between screens.
- **Custom Styling**: The application is styled using TailwindCSS for a clean and modern look.
- **Cross-Platform Compatibility**: Built with React Native, the app functions seamlessly on Android, iOS, and the web.

## Tech Stack

- **React Native**: Framework for building native apps using React.
- **Expo**: Framework and platform for universal React applications.
- **TailwindCSS**: Utility-first CSS framework for custom styling.
- **TypeScript**: A superset of JavaScript for building robust applications.
